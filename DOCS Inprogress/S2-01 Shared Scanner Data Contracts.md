# S2-01 Shared Scanner Data Contracts

## Purpose
Define shared scanner data contracts that scanner, backend, frontend, persistence, and future CVE matching work can use without depending on scanner internals.

## Contract Principles
- Contracts must be serializable to JSON.
- Contracts must avoid raw socket objects, Scapy objects, subprocess output, and other scanner implementation details.
- Optional future fields should be nullable or omitted rather than required.
- Backend, frontend, and persistence code should depend on these shared contracts instead of scanner-specific classes.
- Service identification and vulnerability matching fields may exist as optional fields, but Sprint 2 should not treat those stages as complete unless they are implemented.

## ScanConfiguration
Represents the input settings for a scan.

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `scan_id` | string/null | No | generated by backend/coordinator | Unique scan identifier when available. |
| `targets` | list[string] | No | empty list | Manual targets as IPs, hostnames, or CIDR ranges. |
| `scan_mode` | string | No | `smart` | Requested mode, such as `smart`, `common`, `custom`, or `all`. |
| `ports` | list[integer] | No | smart/common profile | Explicit TCP ports to scan. |
| `port_spec` | string/null | No | null | Original user port expression, such as `22,80,443` or `1-1024`. |
| `timeout_seconds` | number | No | `1.0` | TCP connection timeout per port. |
| `discovery_enabled` | boolean | No | true | Whether host discovery should run. |
| `discovery_network` | string/null | No | local network | Optional CIDR network for discovery. |
| `include_local_host` | boolean | No | true | Whether to include the scanner host in discovery results. |
| `concurrency` | integer | No | scanner default | Maximum worker count for scanning. |
| `created_at` | string/null | No | set at runtime | ISO timestamp for configuration creation. |

Validation requirements:
- At least one manual target or discovery must be enabled.
- Ports must be between 1 and 65535.
- Timeout must be greater than zero.
- Concurrency must be greater than zero.
- Scan mode must be a known value.

## HostObservation
Represents one host known to the scanner.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `ip` | string | Yes | IPv4 address for the host. |
| `hostname` | string/null | No | Hostname if resolved or provided. |
| `mac` | string/null | No | MAC address when known. |
| `discovery_source` | string | Yes | Source such as `local_interface`, `arp_scan`, `neighbor_table`, or `manual_target`. |
| `discovery_status` | string | Yes | Status such as `discovered`, `manual`, `skipped`, or `unreachable`. |
| `last_seen` | string/null | No | ISO timestamp from discovery or normalization. |
| `metadata` | object/null | No | Optional nonessential details for debugging or future use. |

Mapping from current host discovery output:

| Existing Field | Contract Field |
| --- | --- |
| `Device.ip` | `HostObservation.ip` |
| `Device.mac` | `HostObservation.mac` |
| `Device.source` | `HostObservation.discovery_source` |
| `Device.last_seen` | `HostObservation.last_seen` |

## PortObservation
Represents the scanner's observation for one host/port pair.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `host_ip` | string | Yes | Host IPv4 address. |
| `host_mac` | string/null | No | MAC address when available. |
| `port` | integer | Yes | TCP port number. |
| `protocol` | string | Yes | Protocol, currently `tcp`. |
| `state` | string | Yes | Port state such as `open`, `closed`, `filtered`, or `unknown`. |
| `service_hint` | string/null | No | Port-based hint, not verified fingerprinting. |
| `service` | string/null | No | Fingerprinted service name when available. |
| `product` | string/null | No | Fingerprinted product when available. |
| `version` | string/null | No | Fingerprinted version when available. |
| `banner` | string/null | No | Captured banner when available. |
| `confidence` | number/null | No | Confidence score for service fingerprinting. |
| `observed_at` | string/null | No | ISO timestamp for this port observation. |

Mapping from current port scan output:

| Existing Field | Contract Field |
| --- | --- |
| `PortResult.ip` | `PortObservation.host_ip` |
| `PortResult.mac` | `PortObservation.host_mac` |
| `PortResult.port` | `PortObservation.port` |
| `PortResult.protocol` | `PortObservation.protocol` |
| `PortResult.state` | `PortObservation.state` |
| `PortResult.service_hint` | `PortObservation.service_hint` |
| `PortResult.scanned_at` | `PortObservation.observed_at` |

Mapping from current service fingerprinting output:

| Existing Field | Contract Field |
| --- | --- |
| `ServiceFingerprint.service` | `PortObservation.service` |
| `ServiceFingerprint.product` | `PortObservation.product` |
| `ServiceFingerprint.version` | `PortObservation.version` |
| `ServiceFingerprint.banner` | `PortObservation.banner` |
| `ServiceFingerprint.confidence` | `PortObservation.confidence` |

## ScanLifecycleState
Represents the current stage of a scan.

| State | Meaning |
| --- | --- |
| `CREATED` | Scan has been created but work has not started. |
| `DISCOVERING` | Host discovery is running. |
| `SCANNING` | TCP port scanning is running. |
| `IDENTIFYING` | Service identification is running. Future-facing unless fingerprinting is integrated into the coordinator. |
| `MATCHING` | Vulnerability matching is running. Future-facing until CVE matching is implemented. |
| `COMPLETED` | Scan completed successfully. |
| `FAILED` | Scan stopped because of an unrecoverable error. |
| `CANCELLED` | Scan stopped because cancellation was requested. |

## ScanProgress
Represents scan progress for backend status and frontend display.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `scan_id` | string/null | No | Scan identifier when available. |
| `state` | string | Yes | Current `ScanLifecycleState`. |
| `hosts_discovered` | integer | Yes | Number of hosts found or supplied. |
| `hosts_completed` | integer | Yes | Number of hosts fully scanned. |
| `ports_completed` | integer | Yes | Number of host/port checks completed. |
| `total_ports` | integer | Yes | Total planned host/port checks when known. |
| `percent_complete` | number | Yes | Completion estimate from 0 to 100. |
| `current_host` | string/null | No | Host currently being scanned. |
| `current_port` | integer/null | No | Port currently being scanned. |
| `elapsed_seconds` | number | Yes | Time elapsed since scan start. |
| `cancellation_requested` | boolean | Yes | Whether cancellation has been requested. |

## ScannerError
Represents expected scanner or backend-facing failures.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `code` | string | Yes | Machine-readable error code. |
| `message` | string | Yes | Human-readable message safe for UI/API display. |
| `stage` | string | Yes | Stage where the error occurred, such as `configuration`, `discovery`, `scanning`, `identifying`, `matching`, or `aggregation`. |
| `details` | object/null | No | Optional structured diagnostic details. |
| `recoverable` | boolean | Yes | Whether scan may continue after this error. |

Suggested error codes:
- `INVALID_CONFIGURATION`
- `INVALID_TARGET`
- `DISCOVERY_FAILED`
- `SCAN_FAILED`
- `TIMEOUT`
- `CANCELLED`
- `UNSUPPORTED_PLATFORM`
- `INTERNAL_ERROR`

## ScanResult
Represents the final or partial output of one scan.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `scan_id` | string/null | No | Unique scan identifier when available. |
| `configuration` | object | Yes | Configuration summary used for the scan. |
| `state` | string | Yes | Final or current lifecycle state. |
| `started_at` | string/null | No | ISO timestamp when work started. |
| `completed_at` | string/null | No | ISO timestamp when work ended. |
| `hosts` | list[HostObservation] | Yes | Hosts found or supplied. |
| `ports` | list[PortObservation] | Yes | Port observations found during scanning. |
| `progress` | ScanProgress | Yes | Last known progress summary. |
| `errors` | list[ScannerError] | Yes | Errors or warnings collected during the scan. |
| `metadata` | object/null | No | Optional extra details not required by consumers. |
